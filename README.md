# 🎭 خمّن الشخصية (Character Guesser)

لعبة ويب على غرار **Akinator**: فكّر في شخصية مشهورة، أجب عن أسئلة نعم/لا، واللعبة تحاول تخمينها. وإذا أخطأت، **تتعلم منك** شخصيات وأسئلة جديدة، فيصبح ذكاؤها أفضل مع الوقت.

## ✨ المميزات

- ♾️ **عدد غير محدود من الشخصيات**: كل شخصية عبارة عن مجموعة صفات (Attributes)، ويمكن إضافة المزيد بلا حدود.
- 🧠 **محرك ذكي**: يختار في كل خطوة السؤال الذي يقسم الاحتمالات إلى نصفين، بدل شجرة قرار ثابتة.
- 🔁 **لا تكرار للأسئلة**: يُسأل كل سؤال مرة واحدة فقط في الجولة.
- 💾 **حفظ تلقائي (localStorage)**: يتذكر الشخصيات والأسئلة التي تعلّمها بعد إغلاق المتصفح.
- ➕ **وضع التعلّم**: عند الفشل، أدخل اسم الشخصية + سؤالاً يميّزها عن التخمين الخاطئ.
- 🌐 **ملف واحد**: يعمل بفتح `index.html` مباشرة بدون أي تثبيت.
- 📱 **متجاوب** مع الجوال والتابلت والحاسوب.

## 🎮 طريقة اللعب

1. افتح `index.html` في أي متصفح.
2. فكّر في شخصية (حقيقية أو خيالية).
3. أجب عن أسئلة **نعم** / **لا**.
4. إذا خمّنت اللعبة صح، احتفل 🎉 — وإن أخطأت، علّمها:
   - اسم الشخصية.
   - (اختياري) سؤال يميّزها عن التخمين الخاطئ + الإجابة عليه.
5. في المرة القادمة، ستصبح اللعبة أذكى!
