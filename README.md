🎭 خمّن الشخصية (Character Guesser)
لعبة بسيطة على الويب تشبه لعبة "Akinator": يفكر المستخدم في شخصية مشهورة (حقيقية أو خيالية)، ويجيب عن أسئلة نعم/لا، والتطبيق يحاول تخمين الشخصية.
كيف تعمل اللعبة
اللعبة مبنية بملف HTML/CSS/JavaScript واحد فقط (index.html)، وتعتمد على "شجرة قرار" (decision tree) مكتوبة داخل الكود — كل سؤال يقود إلى سؤال آخر أو إلى تخمين نهائي.
التشغيل محليًا
فقط افتح ملف index.html في أي متصفح، بدون الحاجة لأي تثبيت.
النشر على GitHub Pages (مجانًا)
أنشئ مستودعًا (repository) جديدًا على GitHub، مثلاً باسم character-guesser.
ارفع ملف index.html (وهذا الملف) إلى المستودع.
من إعدادات المستودع (Settings) → Pages → اختر الفرع main والمجلد /root.
بعد دقيقة أو اثنتين، سيصبح رابط اللعبة متاحًا على شكل:
https://<اسم-المستخدم>.github.io/character-guesser/
التطوير المستقبلي
إضافة المزيد من الشخصيات والأسئلة لتوسيع شجرة القرار.
حفظ الشخصيات في ملف JSON منفصل بدل كتابتها داخل الكود مباشرة.
إضافة خاصية "تعلّم" بحيث تسأل اللعبة عن شخصية جديدة إذا فشلت في التخمين.
