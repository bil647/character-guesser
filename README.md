# 🎭 خمّن الشخصية (Character Guesser)

لعبة ويب بسيطة على غرار **Akinator**: فكّر في شخصية مشهورة (حقيقية أو خيالية)، أجب عن أسئلة نعم/لا، ودع اللعبة تحاول تخمينها. وإذا فشلت، **تتعلم منك** شخصيات جديدة وتحسّن نفسها تلقائيًا!

## ✨ المميزات

- 🧠 **شجرة قرار ديناميكية**: تتوسع تلقائيًا مع كل جولة، فتصبح أذكى مع الوقت.
- 💾 **حفظ محلي (localStorage)**: يتذكر تعلّماتك حتى بعد إغلاق المتصفح.
- 🎯 **أسئلة ذكية**: لا تتكرر داخل الجولة، وكل سؤال يقلّص الاحتمالات.
- 🌐 **ملف واحد فقط**: يعمل بمجرد فتح `index.html`، بدون أي تثبيت.
- 📱 **متجاوب**: يعمل على الجوال والتابلت والحاسوب.
- 🎨 **واجهة عربية حديثة**: تصميم أنيق مع دعم كامل للاتجاه من اليمين لليسار.
- 🔄 **إعادة تعيين الذاكرة**: زر لمسح التعلّمات والعودة للشخصيات الافتراضية.

## 🎮 كيف تلعب

1. افتح `index.html` في أي متصفح حديث.
2. فكّر في شخصية مشهورة (حقيقية أو خيالية).
3. أجب عن الأسئلة بـ **نعم** أو **لا**.
4. حاول اللعبة تخمين شخصيتك في نهاية الأسئلة.
5. إذا فشلت، علّمها بإدخال:
   - اسم الشخصية.
   - سؤال يميّزها عن التخمين الخاطئ.
   - الإجابة الصحيحة على هذا السؤال (نعم أو لا).
6. في المرة القادمة، ستتذكرها اللعبة!
